# Piece Map Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship `d3-blockmap`, an npm package exposing `createPieceMap` (canvas piece map for up to ~10M blocks) and a thin React `<PieceMap>` wrapper.

**Architecture:** Pure state layer (packed bitset + per-bin `Uint32Array` counters, no DOM/D3) feeds a canvas renderer that writes one `ImageData` column per bin and re-blits only dirty columns once per animation frame. A small orchestrator wires state, renderer, tooltip, `ResizeObserver`, DPR, and CSS-variable theming. React wrapper owns a div ref and delegates to the factory.

**Tech Stack:** TypeScript (strict), `d3-color`, `d3-interpolate`, tsup (ESM + d.ts), Vitest + happy-dom, `@testing-library/react`, oxlint, oxfmt, npm.

## Global Constraints

- TypeScript strict mode. Named exports only. `import type` for type-only imports.
- No `any` (use `unknown`). No magic numbers: named `ALL_UPPER_CASE` constants in `src/constants.ts`. Regexes declared as named constants.
- camelCase for everything except constants. Factory functions returning plain objects; no classes.
- No inline end-of-line comments.
- Block byte sizes must not appear anywhere.
- Bin mapping is exactly `Math.floor(index * binCount / totalBlocks)`.
- Duplicate, non-integer, and out-of-range indices are silently skipped.
- `totalBlocks < 1` or non-integer throws `RangeError`.
- Dependencies: `d3-color`, `d3-interpolate` only (never the `d3` bundle). `react >= 18` optional peer.
- Package exports: `.` and `./react`. ESM only.
- Run `npm run lint`, `npm run format`, `npm test` before every commit.
- Never run `npx biome`.

`src/bitset.ts`:
```ts
import { BITS_PER_BYTE, BYTE_MASK, BYTE_SHIFT } from './constants';

export type Bitset = {
  has(index: number): boolean;
  set(index: number): boolean;
  clear(): void;
  readonly count: number;
};

export const createBitset = (size: number): Bitset => {
  const bytes = new Uint8Array(Math.ceil(size / BITS_PER_BYTE));
  let count = 0;

  return {
    has: (index) => (bytes[index >>> BYTE_SHIFT] & (1 << (index & BYTE_MASK))) !== 0,
    set: (index) => {
      const byte = index >>> BYTE_SHIFT;
      const mask = 1 << (index & BYTE_MASK);
      if ((bytes[byte] & mask) !== 0) return false;
      bytes[byte] |= mask;
      count += 1;
      return true;
    },
    clear: () => {
      bytes.fill(0);
      count = 0;
    },
    get count() {
      return count;
    },
  };
};
```

```ts
export type BlockRange = { start: number; end: number };

export type Bins = {
  readonly binCount: number;
  readonly counts: Uint32Array;
  binOf(index: number): number;
  rangeOf(bin: number): BlockRange;
  sizeOf(bin: number): number;
  rebuild(has: (index: number) => boolean): void;
};

export const createBins = (totalBlocks: number, binCount: number): Bins => {
  const counts = new Uint32Array(binCount);
  const binOf = (index: number): number => Math.floor((index * binCount) / totalBlocks);
  const rangeOf = (bin: number): BlockRange => ({
    start: Math.ceil((bin * totalBlocks) / binCount),
    end: Math.ceil(((bin + 1) * totalBlocks) / binCount),
  });

  return {
    binCount,
    counts,
    binOf,
    rangeOf,
    sizeOf: (bin) => {
      const { start, end } = rangeOf(bin);
      return end - start;
    },
    rebuild: (has) => {
      counts.fill(0);
      for (let index = 0; index < totalBlocks; index += 1) {
        if (has(index)) counts[binOf(index)] += 1;
      }
    },
  };
};
```

`src/state.ts`:
```ts
import { createBitset } from './bitset';
import { createBins } from './bins';
import type { Bins, BlockRange } from './bins';

export type Progress = { completed: number; total: number };

export type PieceState = {
  readonly totalBlocks: number;
  readonly binCount: number;
  resize(binCount: number): void;
  add(indices: ArrayLike<number>): Uint32Array;
  replace(indices: ArrayLike<number>): void;
  has(index: number): boolean;
  fraction(bin: number): number;
  countOf(bin: number): number;
  sizeOf(bin: number): number;
  rangeOf(bin: number): BlockRange;
  progress(): Progress;
};

const EMPTY_DIRTY = new Uint32Array(0);

const isValidIndex = (index: number, totalBlocks: number): boolean =>
  Number.isInteger(index) && index >= 0 && index < totalBlocks;

export const createPieceState = (totalBlocks: number): PieceState => {
  if (!Number.isInteger(totalBlocks) || totalBlocks < 1) {
    throw new RangeError(`totalBlocks must be a positive integer, got ${totalBlocks}`);
  }

  const bitset = createBitset(totalBlocks);
  let bins: Bins = createBins(totalBlocks, 0);

  const add = (indices: ArrayLike<number>): Uint32Array => {
    const hasBins = bins.binCount > 0;
    const dirty = new Set<number>();
    for (let i = 0; i < indices.length; i += 1) {
      const index = indices[i];
      if (!isValidIndex(index, totalBlocks) || !bitset.set(index)) continue;
      if (!hasBins) continue;
      const bin = bins.binOf(index);
      bins.counts[bin] += 1;
      dirty.add(bin);
    }
    return dirty.size === 0 ? EMPTY_DIRTY : Uint32Array.from(dirty);
  };

  return {
    totalBlocks,
    get binCount() {
      return bins.binCount;
    },
    resize: (binCount) => {
      bins = createBins(totalBlocks, binCount);
      bins.rebuild(bitset.has);
    },
    add,
    replace: (indices) => {
      bitset.clear();
      bins.counts.fill(0);
      add(indices);
    },
    has: bitset.has,
    fraction: (bin) => {
      const size = bins.sizeOf(bin);
      return size === 0 ? 0 : bins.counts[bin] / size;
    },
    countOf: (bin) => bins.counts[bin],
    sizeOf: (bin) => bins.sizeOf(bin),
    rangeOf: (bin) => bins.rangeOf(bin),
    progress: () => ({ completed: bitset.count, total: totalBlocks }),
  };
};
```

`sizeOf` and `rangeOf` are wrapped in arrow functions on purpose: `bins` is reassigned on resize, so passing `bins.sizeOf` directly would capture the stale object.

```ts
  OPAQUE_ALPHA,
  THEME_ATTRIBUTES,
} from './constants';

export type Theme = {
  missing: string;
  partialLow: string;
  partialHigh: string;
  complete: string;
};

export type ColorScale = (fraction: number) => Uint8ClampedArray;

const THEME_VARS: Record<keyof Theme, string> = {
  missing: CSS_VAR_MISSING,
  partialLow: CSS_VAR_PARTIAL_LOW,
  partialHigh: CSS_VAR_PARTIAL_HIGH,
  complete: CSS_VAR_COMPLETE,
};

const LAST_INDEX = COLOR_TABLE_SIZE - 1;
const FIRST_PARTIAL_INDEX = 1;
const LAST_PARTIAL_INDEX = LAST_INDEX - 1;

const parseOr = (value: string, fallback: string): string => (rgb(value).displayable() ? value : fallback);

const writeColor = (table: Uint8ClampedArray, index: number, css: string): void => {
  const color = rgb(css);
  const offset = index * BYTES_PER_PIXEL;
  table[offset] = color.r;
  table[offset + 1] = color.g;
  table[offset + 2] = color.b;
  table[offset + 3] = OPAQUE_ALPHA;
};

export const readTheme = (el: HTMLElement): Theme => {
  const style = getComputedStyle(el);
  const read = (key: keyof Theme): string => style.getPropertyValue(THEME_VARS[key]).trim() || DEFAULT_THEME[key];
  return {
    missing: read('missing'),
    partialLow: read('partialLow'),
    partialHigh: read('partialHigh'),
    complete: read('complete'),
  };
};

export const createColorScale = (theme: Theme): ColorScale => {
  const table = new Uint8ClampedArray(COLOR_TABLE_SIZE * BYTES_PER_PIXEL);
  const partial = interpolateRgb(
    parseOr(theme.partialLow, DEFAULT_THEME.partialLow),
    parseOr(theme.partialHigh, DEFAULT_THEME.partialHigh),
  );

  writeColor(table, 0, parseOr(theme.missing, DEFAULT_THEME.missing));
  writeColor(table, LAST_INDEX, parseOr(theme.complete, DEFAULT_THEME.complete));
  for (let i = FIRST_PARTIAL_INDEX; i <= LAST_PARTIAL_INDEX; i += 1) {
    writeColor(table, i, partial(i / LAST_INDEX));
  }

  return (fraction) => {
    let index = Math.round(fraction * LAST_INDEX);
    if (fraction > 0 && index < FIRST_PARTIAL_INDEX) index = FIRST_PARTIAL_INDEX;
    if (fraction < 1 && index > LAST_PARTIAL_INDEX) index = LAST_PARTIAL_INDEX;
    const offset = index * BYTES_PER_PIXEL;
    return table.subarray(offset, offset + BYTES_PER_PIXEL);
  };
};

export const watchTheme = (onChange: () => void): (() => void) => {
  const observer = new MutationObserver(onChange);
  observer.observe(document.documentElement, {
    attributes: true,
    attributeFilter: [...THEME_ATTRIBUTES],
  });
  const media = matchMedia(DARK_SCHEME_QUERY);
  media.addEventListener('change', onChange);
  return () => {
    observer.disconnect();
    media.removeEventListener('change', onChange);
  };
};
```

```ts
import type { ColorScale } from './colors';
import { BYTES_PER_PIXEL, CANVAS_ROWS } from './constants';

export type ImageDataLike = {
  readonly data: Uint8ClampedArray;
  readonly width: number;
  readonly height: number;
};

export type Canvas2dLike = {
  createImageData(width: number, height: number): ImageDataLike;
  putImageData(image: ImageDataLike, dx: number, dy: number): void;
};

export type RenderSource = {
  readonly totalBlocks: number;
  readonly binCount: number;
  fraction(bin: number): number;
  has(index: number): boolean;
};

export type Scheduler = {
  request(callback: () => void): number;
  cancel(handle: number): void;
};

export type Renderer = {
  setColors(scale: ColorScale): void;
  markDirty(bins: ArrayLike<number>): void;
  markAllDirty(): void;
  destroy(): void;
};

const NO_FRAME = 0;

export const RAF_SCHEDULER: Scheduler = {
  request: (callback) => requestAnimationFrame(callback),
  cancel: (handle) => cancelAnimationFrame(handle),
};

export const createRenderer = (
  ctx: Canvas2dLike,
  source: RenderSource,
  scheduler: Scheduler = RAF_SCHEDULER,
): Renderer => {
  let image: ImageDataLike | undefined;
  let scale: ColorScale | undefined;
  let frame = NO_FRAME;
  let allDirty = false;
  const dirty = new Set<number>();

  const ensureImage = (): ImageDataLike | undefined => {
    const { binCount } = source;
    if (binCount === 0) return undefined;
    if (!image || image.width !== binCount) {
      image = ctx.createImageData(binCount, CANVAS_ROWS);
      allDirty = true;
    }
    return image;
  };

  const writeColumn = (target: ImageDataLike, column: number, color: Uint8ClampedArray): void => {
    target.data.set(color, column * BYTES_PER_PIXEL);
  };

  const paintDiscrete = (target: ImageDataLike, colors: ColorScale): void => {
    const { totalBlocks, binCount } = source;
    for (let block = 0; block < totalBlocks; block += 1) {
      const color = colors(source.has(block) ? 1 : 0);
      const start = Math.floor((block * binCount) / totalBlocks);
      const end = Math.floor(((block + 1) * binCount) / totalBlocks);
      for (let column = start; column < end; column += 1) writeColumn(target, column, color);
    }
  };

  const paintBins = (target: ImageDataLike, colors: ColorScale): void => {
    if (allDirty) {
      for (let bin = 0; bin < source.binCount; bin += 1) writeColumn(target, bin, colors(source.fraction(bin)));
      return;
    }
    dirty.forEach((bin) => writeColumn(target, bin, colors(source.fraction(bin))));
  };

  const paint = (): void => {
    frame = NO_FRAME;
    const target = ensureImage();
    if (!target || !scale) {
      dirty.clear();
      allDirty = false;
      return;
    }
    if (source.totalBlocks < source.binCount) paintDiscrete(target, scale);
    else paintBins(target, scale);
    ctx.putImageData(target, 0, 0);
    dirty.clear();
    allDirty = false;
  };

  const schedule = (): void => {
    if (frame === NO_FRAME) frame = scheduler.request(paint);
  };

  return {
    setColors: (next) => {
      scale = next;
      allDirty = true;
      schedule();
    },
    markDirty: (bins) => {
      for (let i = 0; i < bins.length; i += 1) dirty.add(bins[i]);
      if (bins.length > 0) schedule();
    },
    markAllDirty: () => {
      allDirty = true;
      schedule();
    },
    destroy: () => {
      if (frame !== NO_FRAME) scheduler.cancel(frame);
      frame = NO_FRAME;
      dirty.clear();
    },
  };
};
```

```ts
    const binCount = Math.round(cssWidth * dpr);
    canvas.width = binCount;
    state.resize(binCount);
    renderer.markAllDirty();
  };

  const onDprChange = (): void => {
    dpr = devicePixelRatio;
    layout();
    watchDpr();
  };

  const watchDpr = (): void => {
    dprMedia?.removeEventListener('change', onDprChange);
    dprMedia = matchMedia(dprQuery(dpr));
    dprMedia.addEventListener('change', onDprChange, { once: true });
  };

  const resizeObserver = new ResizeObserver((entries) => {
    const entry = entries[0];
    if (!entry) return;
    cssWidth = entry.contentRect.width;
    layout();
  });
  resizeObserver.observe(container);

  const onPointerMove = (event: PointerEvent): void => {
    const { binCount, totalBlocks } = state;
    if (binCount === 0) return;
    const column = Math.min(binCount - 1, Math.max(0, Math.floor(event.offsetX * dpr)));
    const text =
      totalBlocks < binCount
        ? (() => {
            const block = Math.floor((column * totalBlocks) / binCount);
            return formatBlockTooltip(block, state.has(block));
          })()
        : formatBinTooltip(state.rangeOf(column), state.countOf(column));
    tooltip.show(event.offsetX, text);
  };
  const onPointerLeave = (): void => tooltip.hide();

  canvas.addEventListener('pointermove', onPointerMove);
  canvas.addEventListener('pointerleave', onPointerLeave);
  const unwatchTheme = watchTheme(applyTheme);
  watchDpr();
  applyTheme();
  if (options.initialBlocks) state.add(options.initialBlocks);

  return {
    setBlocks: (indices) => {
      if (destroyed) return;
      state.replace(indices);
      renderer.markAllDirty();
    },
    addBlocks: (indices) => {
      if (destroyed) return;
      renderer.markDirty(state.add(indices));
    },
    getProgress: () => state.progress(),
    destroy: () => {
      if (destroyed) return;
      destroyed = true;
      resizeObserver.disconnect();
      unwatchTheme();
      dprMedia?.removeEventListener('change', onDprChange);
      canvas.removeEventListener('pointermove', onPointerMove);
      canvas.removeEventListener('pointerleave', onPointerLeave);
      renderer.destroy();
      tooltip.destroy();
      canvas.remove();
    },
  };
};
```

```tsx
import { forwardRef, useEffect, useImperativeHandle, useRef } from 'react';
import type { CSSProperties } from 'react';
import { createPieceMap } from '../pieceMap';
import type { PieceMap as PieceMapInstance } from '../pieceMap';

export type PieceMapProps = {
  totalBlocks: number;
  blocks?: ArrayLike<number>;
  className?: string;
  style?: CSSProperties;
};

export type PieceMapHandle = Pick<PieceMapInstance, 'addBlocks' | 'getProgress'>;

const EMPTY_BLOCKS: readonly number[] = [];
const EMPTY_PROGRESS = { completed: 0, total: 0 };

export const PieceMap = forwardRef<PieceMapHandle, PieceMapProps>(({ totalBlocks, blocks, className, style }, ref) => {
  const containerRef = useRef<HTMLDivElement>(null);
  const instanceRef = useRef<PieceMapInstance>(null);

  useEffect(() => {
    const container = containerRef.current;
    if (!container) return undefined;
    const instance = createPieceMap(container, { totalBlocks });
    instanceRef.current = instance;
    return () => {
      instance.destroy();
      instanceRef.current = null;
    };
  }, [totalBlocks]);

  useEffect(() => {
    instanceRef.current?.setBlocks(blocks ?? EMPTY_BLOCKS);
  }, [totalBlocks, blocks]);

  useImperativeHandle(
    ref,
    () => ({
      addBlocks: (indices) => instanceRef.current?.addBlocks(indices),
      getProgress: () => instanceRef.current?.getProgress() ?? { ...EMPTY_PROGRESS, total: totalBlocks },
    }),
    [totalBlocks],
  );

  return <div ref={containerRef} className={className} style={style} />;
});

PieceMap.displayName = 'PieceMap';
```

````markdown
# d3-blockmap

Canvas piece map for download progress across millions of opaque blocks. One column per device pixel, D3 colour interpolation, dirty-column blitting once per frame.

## Install

```bash
npm i d3-blockmap
```

## Structure

| Export | From | Purpose |
|---|---|---|
| `createPieceMap(container, options)` | `d3-blockmap` | Vanilla factory. Returns `PieceMap`. |
| `PieceMap`, `PieceMapOptions`, `Progress`, `Theme` | `d3-blockmap` | Types. |
| `<PieceMap>` | `d3-blockmap/react` | React wrapper, `forwardRef` to `PieceMapHandle`. |
| `PieceMapProps`, `PieceMapHandle` | `d3-blockmap/react` | Types. |

## Usage

```ts
import { createPieceMap } from 'd3-blockmap';

const map = createPieceMap(document.querySelector('#pieces')!, {
  totalBlocks: 10_000_000,
  initialBlocks: downloadedSoFar,
});

socket.on('pieces', (indices: Uint32Array) => map.addBlocks(indices));
map.getProgress(); // { completed, total }
map.destroy();
```

## API

### `createPieceMap(container, options)`

| Option | Type | Notes |
|---|---|---|
| `totalBlocks` | `number` | Positive integer, up to ~10M. |
| `initialBlocks` | `ArrayLike<number>` | Optional. Indices already complete. |

Returns:

| Method | Description |
|---|---|
| `setBlocks(indices)` | Replace all state. |
| `addBlocks(indices)` | Add newly completed indices. O(indices). Duplicates and out-of-range skipped. |
| `getProgress()` | `{ completed, total }`. |
| `destroy()` | Remove canvas, tooltip, observers. Idempotent. |

### Theming

Colours are read from CSS custom properties on the container at start and on theme change (`class`, `style`, `data-theme` on `<html>`, or `prefers-color-scheme`).

| Property | Default |
|---|---|
| `--piece-missing` | `#2b2b2b` |
| `--piece-partial-low` | `#5b3a00` |
| `--piece-partial-high` | `#e0a500` |
| `--piece-complete` | `#2ecc71` |

Fully missing and fully complete bins use the exact endpoint colours; partial bins interpolate between the two partial colours.

### Behaviour

- Bin count equals rendered width in device pixels. Blocks map to bins by `floor(index × binCount / totalBlocks)`.
- When `totalBlocks` is less than the width, each block is drawn as a discrete segment.
- Hovering shows block range, count, and percentage for the column.
- Resize and `devicePixelRatio` changes rebuild bins from the internal bitset in one pass.
````
